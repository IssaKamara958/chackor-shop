Projet E-commerce : Chackor Shop

Une boutique en ligne moderne pour la vente de Café Touba et de services événementiels.

Concept du Projet

Chackor Shop est une application web e-commerce complète, développée pour Chackor Organisation. Elle permet de présenter et vendre des produits artisanaux (Café Touba) ainsi que des services. L'application est conçue pour être performante, sécurisée, et offrir une expérience utilisateur fluide et moderne sur tous les appareils (mobile, tablette, ordinateur).

Architecture et Technologies

Ce projet n'est pas un site web statique traditionnel. Il utilise une architecture JavaScript moderne basée sur React et son framework de production Next.js. Cette approche permet de créer des interfaces utilisateur dynamiques et réactives.

Le "backend" (logique serveur) est intégré directement dans le projet Next.js via des API Routes, qui communiquent avec une base de données MySQL pour gérer les produits, les utilisateurs et les commandes de manière dynamique.

Outils et Bibliothèques Clés

  • Framework Principal : Next.js & React Pour construire l'interface utilisateur et gérer la logique serveur.
  • Langage : TypeScript Pour un code plus sûr, plus clair et plus facile à maintenir.
  • Styling : Tailwind CSS Pour un design rapide, moderne et entièrement personnalisable.
  • Composants UI : Shadcn/ui Pour des éléments d'interface réutilisables (boutons, formulaires, etc.).
  • Base de Données : MySQL Pour stocker les données de l'application (produits, commandes...).
  • Gestion d'État : React Context Pour gérer l'état du panier d'achat de manière globale.
  • Validation de Données : Zod Pour s'assurer que les données envoyées via les formulaires sont correctes.
  • Rendu 3D : React Three Fiber Pour l'intégration de l'assistant virtuel animé en 3D.

Fonctionnalités Principales

  • Catalogue de produits : Affichage des produits depuis une base de données MySQL.
  • Panier d'achat interactif : Ajout, modification de quantité et suppression d'articles sans rechargement de page.
  • Processus de commande : Formulaire de paiement avec validation des données et calcul des frais de port.
  • Notification de commande : La commande est finalisée via une redirection vers WhatsApp.
  • Design Responsive : L'interface s'adapte à toutes les tailles d'écran.

Pour Visualiser le Code Source Complet

Le code source n'est pas contenu dans un unique fichier HTML/CSS/JS, mais est structuré en de multiples fichiers et dossiers conformément aux conventions de Next.js.

Pour l'explorer, il faut ouvrir le projet dans un éditeur de code (comme Visual Studio Code) et naviguer dans l'arborescence des fichiers, principalement dans le dossier /src.
